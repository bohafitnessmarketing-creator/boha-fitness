Novo mapa

Comece em branco ou de um modelo pronto. Dá para mudar tudo depois.

Mapa como texto

Cada linha é um tópico; o recuo (2 espaços ou Tab) define o nível. Use [ ] e [x] para tarefas. Dá para colar uma lista de qualquer lugar.

Histórico de versões

O sistema guarda versões sozinho enquanto você edita. Você também pode salvar uma versão com nome antes de uma grande mudança. Restaurar não apaga nada: a versão atual também fica guardada.
